Worker allocation

Transparent rule score · not a trained AI model

Skill match: 40 points; availability: 25; distance: up to 20 (2 points deducted per kilometer); workload: up to 15. High priority applies the strictest workload penalty. The server recalculates before assigning; an administrator confirms the assignment.
