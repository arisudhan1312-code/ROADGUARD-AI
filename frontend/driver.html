Available route options

The suggestion minimizes a transparent risk sum for verified active hazards within 100 m (Critical 8, High 5, Medium 3, Low 1; unrated 2), then uses OSRM-reported duration and distance as tie-breakers. If hazard data is unavailable, the suggestion uses OSRM estimates only. Known reports can be incomplete, so no route is guaranteed hazard-free. The public OSRM demo service may be rate-limited.

Place-name lookup uses the public OpenStreetMap Nominatim service; route requests include the entered start and destination. Network access is required. Avoid entering sensitive locations.
